01一句话串起这七篇

七篇论文其实围绕同一个大命题——「神经（大模型）」和「符号（BT / 规约 / 规划）」怎么闭环，只是各自攻克一个环节：
表示
把什么当作可进化的符号工件
EPM(记忆) · VASO(合约) · BT(VersualRL / StructuredRobotPolicies / CABTO)
反馈
用什么信号驱动进化
VASO(形式反例) · LLM-GROP(ASP约束) · VersualRL(视觉批评) · LeTS-Drive(环境奖励)
数据
数据从哪来、怎么学
SynthDemo-RL(合成教师+SFT+PPO) · StructuredRobotPolicies(合成监督) · EPM(特权启发式造标签)
CABTO 的生态位
CABTO 恰好站在这三条线的交叉点上：它既有「符号工件」（动作模型 + BT 系统）、又有「形式化验证」（completeness / consistency），唯独缺「可学习化」（低层策略、感知、跨任务积累）。下面三篇的组合拳正是补这三块。

03七篇逐篇详解

EPM · Embodied Perception Memory（可学习记忆）

ICLR 2026 · Meta FAIR
把「世界状态」做成一个可学习的、跨帧增量维护的对象。

解决什么：动态环境里机器人要记住「物体在哪、什么状态」，但旧记忆难应对物体移动、多模型拼接又贵、查询接口不实用。

怎么做：单个 VLM 从第一人称观测出发，用 Add / Update / Remove 三种操作增量维护一份文本环境清单（物体 = 3D 坐标 + 语言描述），直接喂给 LLM 规划器；用「特权信息 + 启发式」造数据做 LoRA 微调；规划器用「人类示范模仿(HD) + 难度感知 RL(DDAFT)」训练。

结果：比强基线 +55% 成功率，8B 模型反超 70B 零样本。

给 CABTO：可学习记忆 + 免查询接口 + rollout/RFT 训练范式。

VASO · 形式可验证自进化技能

arXiv 2606.05395 · UT Austin
把「形式化验证的反例」变成「技能自进化的优化信号」。

解决什么：基础模型让「造技能」便宜了，但「信技能」还贵——执行反馈等 trace 级证据覆盖不了时序安全契约。

怎么做：每个技能 = 语义合约（LTL 规约 + 命题对齐的标注函数），两级验证（技能级过滤逻辑矛盾 + 计划级模型检查），失败时把反例轨迹翻译成「文本梯度」迭代改写合约，冻结权重纯 prompt 层操作。

结果：97.2% 规约符合率，<100 样本、每技能 <20 分钟。

给 CABTO：把「VLM 软校验」升级成「可验证反例驱动的精炼」。

LLM-GROP · 视觉接地的任务运动规划

IJRR 2025 · SUNY / UT Austin / Sony AI
LLM 常识解决「放哪」，视觉组件解决「站哪」，联合优化可行性 + 效率。

解决什么：欠指定指令（摆一桌餐具）需要常识；移动操作要选对站立位置（同时决定导航可行性与操作可达性）。

怎么做：LLM 常识生成布局（符号空间关系 → 几何关系，ASP 一致性检查 + 拒绝采样兜底），GROP 用 FCN 学「可行性热图」选站立位置，效用函数 U = R·F − C 联合优化。

结果：真机 84.4% 成功率，用户评分优于三类基线。

给 CABTO：LLM 当「候选生成器」+ 符号约束兜底的结构。

VersualRL · 闭环言语强化学习

IROS 2026 · Skoltech
VLM critic 看执行轨迹给结构化批评，LLM actor 在符号层改行为树。

解决什么：真机执行不确定性下，深度 RL 子符号策略黑盒难调试，LLM 规划器又开环缺物理反馈。

怎么做：VLM critic（视觉快照 + BT 轨迹 → 结构化批评 + 告警分 + 置信度）+ LLM actor（专家节点库上做离散 BT 编辑），两模型冻结、零梯度、零仿真。

结果：可解释的策略进化；微调 3B critic 优于未调 7B；因果归因质量 > 感知精度。

给 CABTO：同构 BT 闭环，但只改结构不做接地——是需压住的对手，也是可借的「结构化反馈」范式。

SynthDemo-RL · 合成示范打破零奖励困境

arXiv 2609.21650 · Fujitsu
自动化教师先「点亮」零奖励任务，稀疏奖励 RL 再拉高平均分。

解决什么：VLA 迁到新任务、又没人演示时，稀疏二值奖励的 RL 探索不出任何成功轨迹（大量任务恒为 0%）。

怎么做：自动化教师（GraspGen 抓取 + LLM 失败调参 + 脚本执行）从仿真特权状态合成成功轨迹 → SFT 蒸馏进学生 → PPO 稀疏奖励精调。核心诊断指标 reward coverage（至少成功一次的任务占比）。

结果：27 个零成功任务全部救活，LIBERO-PRO 平均 97.8% / 97.1%。

给 CABTO：合成教师点亮零奖励 + 稀疏 RL 的完整配方。

LeTS-Drive · 规划-学习闭环

IEEE T-RO · NUS
「局部规划、全局学习」——学习启发式让短时程搜索近似长时程规划。

解决什么：密集无规则交通下长时程 POMDP 搜索树指数爆炸、无法实时。

怎么做：在线规划器做短时程信念树搜索，策略 / 价值网络做长时程启发式引导（复杂度 O(|A|^H K) → O(|A|^D K)）；学习器从规划器经验更新网络、反哺规划器，闭环互提升。价值裁剪保证近最优性 + 训练稳定。

结果：闭环 ~1/10 数据追平开环；场景越密收益越大；带理论保证。

给 CABTO：「规划器蒸馏结构化价值 → 学习器 → 反哺规划器」的数据飞轮。

StructuredRobotPolicies · 合成神经符号监督

arXiv 2604.02812 · Padova / Fraunhofer
纯合成数据训练 VLM，从视觉直接合成可执行行为树（vision-to-BT）。

解决什么：end-to-end 策略黑盒难分析 + 真人示范数据稀缺。

怎么做：自动化管线程序化生成 10,000 个 domain-randomized 合成样本（场景 + instruction-policy 对），LoRA 微调 12B VLM 学「结构化空间-符号映射」，从视觉 + 指令 + 系统规约直接输出 BT。

结果：零真实数据训练，Franka Panda + UR5e 两异构机械臂零样本真机迁移。

给 CABTO：离 CABTO 最近——证明了「BT 合成可以被合成数据训练」。

04三条组合拳（如何落地）

组合拳 1 · SynthDemo-RL：合成教师点亮零奖励 → 稀疏奖励 RL

映射：CABTO 的「自动化教师」= 你现成的 world_state oracle + PrimitiveRunner 脚本原语 + oracle 位姿；「一致性验证」= 稀疏二值奖励。

  • 先用 oracle 教师为每个 ⟨h, π⟩ 动作模型生成至少一条成功执行轨迹（点亮零奖励）；
  • 再把成功轨迹蒸馏成训练信号，用「一致性达标=1 / 否则=0」做 RFT / PPO。
组合拳 2 · EPM：可学习记忆替代单帧打点 + oracle 谓词

训练一个 VLM，输入 RGB + 旧谓词状态 + 动作，输出谓词更新（Add / Remove / No updates），跨帧增量维护世界状态。

  • 先谓词级（替代 world_state.compute_state 的 oracle）；
  • 再物体级（拿 3D 坐标，替代 Qwen 打点 + known_height）。
组合拳 3 · VASO：形式反例 → 文本梯度，升级跨层精化

CABTO 的 consistency 定义本身就是 STRIPS 形式化的，check_effect 的 violations 就是反例雏形。

  • 把 violations 从「二值 check 结果」升级成「结构化、可归因、可反哺动作模型修订」的文本梯度；
  • 精确到「动作模型 h 的 add 效应 lift(obj) 未达成，因低层策略 grasp 深度不足」。

05落地小结

一条线串起三条组合拳
  1. 造数据：用 world_state oracle + 脚本原语当「教师」，为每个动作模型点亮零奖励（SynthDemo-RL 范式）；
  2. 学记忆：用这些数据训一个「CABTO-EPM」，替代单帧打点 + oracle 谓词（EPM 范式）；
  3. 精化：把一致性违背编译成形式反例 → 文本梯度，驱动动作模型可验证地修订（VASO 范式）。

三条正好对应 TPAMI 报告里的方向 E（RL 低层策略）、B（学习谓词）、C（可验证 grounding），是「可学习化改造 CABTO」的一条完整路径。
