一、调研目标与关键相关工作

调研问题：2024–2026 年，机器人系统修复领域有哪些新方法可为 CABTO 提供核心算法？重点关注跨层修复、因果干预、反事实验证、覆盖保持、主动测试选择。

关键相关工作（划定了当前技术边界）

工作核心方法与 CABTO 关系局限
MAGMA-GEN（CoRL 2026）特权教练假设决策错误 + 反事实重执行验证最接近"失败归因+修复"只修决策层，不跨层，无覆盖约束
RE-0（2026-09）教师局部纠正 + 反事实验证 + 干预信用分配 + 收益下界理论有理论保证的修复递归蒸馏，非动作模型修复
Interventional Causal Circuits（2026-07）JPT + 因果变量排序 + 干预电路 + 支撑确定性验证用因果干预定位参数单变量单层，不跨层，无覆盖约束
CoRe（2026-08）推理时反事实想象恢复免训练恢复无模型修复，无覆盖约束
DrBO（ICLR 2025）因果发现 + 贝叶斯优化因果发现方法非机器人修复
Active Intervention Design（Nature MI 2023）因果主动学习识别最优干预主动干预选择非机器人，无覆盖约束
关键空白：没有工作同时做到——跨层（动作模型+策略）联合修复 + 显式任务覆盖保持 + 因果干预定位 + 反事实验证。这是 CABTO 冲击 TPAMI 的机会窗口。

二、核心算法方向 A：跨层因果干预修复（CLCIR）

Cross-Layer Causal Intervention Repair

算法流程

输入：失败的 BT 系统（动作模型 h, 策略 π），失败证据 E，已有任务集 T
输出：修复后的系统（h', π'），保证 ∀t∈T 仍可完成

步骤 1：构建跨层因果图 CLCG
  节点：
    M = {动作模型参数}（如 pick.pre, stack.add）
    P = {策略参数}（如 grasp_offset, approach_speed）
    S = {观测状态}（如 finger_force, object_pose）
    R = {执行结果}（如 success, transition_match）
  边：从历史执行数据学习因果依赖
    M → P（模型参数决定策略该做什么）
    P → S（策略参数影响观测状态）
    S → R（观测状态决定执行结果）

步骤 2：干预因果诊断（识别根因层和参数）
  对每个候选干预变量 x_i ∈ M ∪ P：
    计算 ρ_i(x̂_i) = 干预分布下观测值的合理性
    （用 Interventional Causal Circuits 的 JPT + 支撑确定性验证）
  主因 = argmin ρ_i
  定位层 = 若主因 ∈ M 则模型层，若 ∈ P 则策略层

步骤 3：生成跨层联合修复候选
  根据主因层生成候选修复（改模型 / 改策略 / 联合）
  生成方式：LLM 提议（受因果诊断引导）或规则模板

步骤 4：反事实验证筛选
  对每个候选修复 c：
    在相同状态 s、匹配条件下重执行
    只保留能改善下游进展的修复（借鉴 MAGMA-GEN）

步骤 5：覆盖约束检查
  验证修复后的系统是否仍能完成所有已有任务 t ∈ T

步骤 6：返回满足覆盖约束的最优修复

理论分析

  • 后悔界限（借鉴 RE-0）：每轮修复收益 ≥ 验证干预收益 −（验证误差+投影误差），保证单调改进
  • 因果可辨识性：跨层因果图在什么条件下可辨识根因层
  • 覆盖保持：约束优化保证修复不降低任务覆盖

新颖性

  • 跨层因果干预：vs Interventional Causal Circuits 的单层单变量，CLCIR 是跨层联合干预
  • 显式覆盖约束：vs MAGMA-GEN/RE-0 无覆盖约束，CLCIR 把覆盖保持作为硬约束
  • 因果引导+反事实验证+约束优化：组合创新

三、核心算法方向 B：覆盖约束的修复合成（CCRS）

Coverage-Constrained Repair Synthesis

算法流程

输入：失败的 BT 系统，失败反例 F，已有任务集 T，规约 Σ
输出：修复后的系统，保证满足规约且覆盖所有 T

步骤 1：从失败反例提取一致性约束
  修复后的系统必须满足实际转移

步骤 2：从已有任务提取覆盖约束
  ∀t∈T, planable(h', t) ∧ executable(π', t)

步骤 3：规约约束（如 LTL 规约）

步骤 4：约束求解 / 程序合成
  用 CSP 求解器或程序合成器，直接合成满足所有约束的修复

步骤 5：验证合成的修复

新颖性

  • 覆盖约束作为硬约束（vs 事后检查）
  • 约束求解/程序合成视角（vs 启发式搜索）
  • 直接合成修复（vs 生成候选再验证）

CCRS 颠覆 CABTO：把"启发式搜索+事后验证"替换为"约束求解+直接合成"，是范式层面的改变。

四、核心算法方向 C：后悔界限驱动的主动诊断与修复（RB-ADR）

Regret-Bounded Active Diagnosis and Repair

算法流程

输入：初始 BT 系统，任务集 T，预算 B
输出：最优修复系统，后悔有界

定义：
  状态 s_t = 当前对系统的信念
  动作 a_t = 选择测试（运行任务）或修复（改参数）
  奖励 r_t = 系统性能提升（修复成功率 + 覆盖保持）
  后悔 Regret(T) = Σ_t (最优系统性能 − 当前系统性能)

步骤 1：初始化对系统的信念（先验）
步骤 2：主动测试选择（贝叶斯优化/Thompson sampling）
  选最大化预期信息增益或修复价值的测试
步骤 3：执行测试，更新信念（后验）
步骤 4：信念足够确定时应用修复
步骤 5：后悔界限保证收敛到最优系统

新颖性

  • 后悔界限理论（vs 启发式）
  • 主动测试选择（vs 穷举/随机）
  • 序列决策视角（vs 单步修复）

推荐：CLCIR 为主线

  1. 可行性最高：最直接建立在 CABTO 现有基础上，能复用 P0/P1/P2 实验设置
  2. 新颖性明确：跨层因果干预+覆盖约束，文献中无先例
  3. 有具体算法：干预因果电路+反事实验证+约束优化，每个组件都有成熟技术可借鉴
  4. 理论可分析：后悔界限、覆盖保持、因果可辨识性都有明确分析空间
  5. 实验可操作：用 CABTO 现有 P0/P1/P2 设置就能验证

CCRS 作为补充/未来方向：当因果干预不够时，用约束合成兜底。RB-ADR 作为理论增强：为 CLCIR 加后悔界限理论保证。

CLCIR 冲击 TPAMI 的论证要点

  1. 问题新颖性：跨层（动作模型+策略）联合修复+显式覆盖保持，机器人修复领域是新的
  2. 方法新颖性：因果干预电路+反事实验证+约束优化的组合，是新的方法
  3. 与 MAGMA-GEN 区分：MAGMA-GEN 修决策层（不跨层），CLCIR 修动作模型+策略（跨层），且有覆盖约束
  4. 与 Interventional Causal Circuits 区分：后者单层单变量干预，CLCIR 跨层联合干预+覆盖约束
  5. 理论保证：后悔界限+覆盖保持+因果可辨识性
  6. 实验验证：用 CABTO 的 P0/P1/P2 设置，对比原版、规则修复、固定搜索、CLCIR
