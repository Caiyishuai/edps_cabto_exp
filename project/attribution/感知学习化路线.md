# 感知学习化路线：从「打点」到「可学习记忆」

> 本文记录「打点方案本质依赖」的诊断，以及通用化 + scaling up 的三条腿。
> 与 `README.md`（归因探针 + 三层瓶颈）互补：README 讲"问题在哪"，本文讲"往哪走"。

---

## 一、核心判断（划重点）

> **打点方案的本质依赖，是「感知没学习化」。要通用 + scale，就得把「零样本单帧打点 + 手工先验」换成「可学习的跨帧 3D 状态维护（EPM 式记忆）」，用仿真特权信息造长尾数据训练，用归因探针 + 反例做闭环精炼。这不是「再找一个更强的打点器」，而是把感知从「函数」升级成「会记、会学、会纠错的世界模型」。**

## 二、打点方案的四个手工先验（脆弱点）

| 先验 | 是什么 | 失效场景 |
|---|---|---|
| 零样本 3B 打点 | 靠 Qwen2.5-VL 零样本视觉定位 | 难辨物体（potato/shrimp）、遮挡 |
| 已知高度反投影 | 物体 z = 桌面 + 半高 | 空中物体（双臂交接/接球/搬箱） |
| 颜色先验 | 手写 HSV 阈值 `refine_rgb` | 颜色相近物体 |
| 单帧无记忆 | 每动作重新打点 | 遮挡/移动、多实例 |

这些是"为桌面静态窄域手工调出来的"，不通用、不可 scale——每换物体要手写 mask、每换场景要重标高度。

## 三、三条腿（通用 + scale）

### 腿 1：感知学习化（治本）—— 训练 CABTO-EPM

把 `grasp_point()` / `destination_point()` 的"打点 + 反投影"，换成一个**可学习的记忆模型**：

- 输入：RGB 观测 + 相机位姿 + 上一时刻记忆
- 输出：`Add / Update / Remove`（物体 + 3D 坐标 + 状态描述）

同时解决四个先验：空中高度（记忆存 3D，跨帧融合）、难辨物体（训练学会区分）、单帧脆弱（跨帧记忆）、颜色先验（训练学语义）。

### 腿 2：数据规模化 —— 合成特权监督，覆盖长尾

用仿真器特权信息（`pos(obj)` 真值 + `render_cam`）造海量数据，**故意注入难例**：

- 遮挡（物体被臂/其他物体挡住）
- 空中物体（模拟双臂交接的高度变化）
- 难辨物体（颜色相近、多实例）
- 动态（物体被移动后记忆要 Update/Remove）

### 腿 3：闭环验证 —— 归因探针 + 形式反例

已有的三个探针（oracle / vlm+oracle / vlm+qwen）接进闭环：感知失败时定位"记忆错 / 策略错 / 执行错"，用反例驱动定向精炼（VASO 式），而非盲目重采样。

## 四、第一步：最小 EPM 切片

**目标**：在 cover 上，用 `pos(obj)` 真值造一批 `(RGB 观测 → 物体 3D 坐标 + 状态)` 数据，
微调 Qwen-VL，验证它能否"看图直接输出物体 3D 坐标"（替代打点 + 已知高度反投影），
并在难辨物体、遮挡下测鲁棒性。

**若成立** → "学习化的感知"立住了，scale 才有地基。

- 数据采集脚本：`collect_epm_data.py`
- 训练：LoRA 微调 Qwen2.5-VL（复用 `LocalModel` / `mlx-vlm`）
- 验证：难辨物体（颜色相近）+ 遮挡场景下的 3D 坐标回归误差

## 五、顺序提醒（吸取本轮的教训）

1. 先别急着训练——先用归因探针确认"打点方案"卡在哪（已做：单帧 + 已知高度 + 颜色先验）；
2. 再上最小 EPM 切片——先验证"记忆化感知"在 cover 上是否真更鲁棒；
3. 最后 scale 到双臂——空中高度、遮挡用腿 2 的合成数据覆盖。
